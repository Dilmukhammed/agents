# Система агентов для составления плана действий

Этот проект представляет собой систему агентов, использующих несколько языковых моделей (LLM) для совместной разработки плана действий. Процесс состоит из трех этапов:

1.  **Генерация первоначальных планов:** Несколько LLM параллельно создают свои варианты плана в формате JSON на основе запроса пользователя. Система использует Pydantic для валидации структуры ответа.
2.  **Обсуждение и доработка:** Модели анализируют JSON-планы друг друга, высказывают критику и предложения по улучшению в текстовом формате.
3.  **Создание финального плана:** Отдельная LLM анализирует все предложения и создает единый, итоговый план в текстовом формате.

## Структура проекта

*   `agents/main.py`: Основной файл с логикой работы агентов.
*   `agents/schemas.py`: Файл с Pydantic-моделями для валидации JSON-планов.
*   `config.json`: Файл конфигурации для указания моделей и API-ключей.
*   `system_prompts/`: Папка с текстовыми файлами системных промптов для каждого этапа.
*   `all_plans.txt`: Файл, в котором сохраняются первоначальные JSON-планы и текстовые обсуждения.
*   `final_plan.txt`: Файл с итоговым планом.

## Инструкция по запуску

1.  **Установите зависимости:**
    ```bash
    pip install openai pydantic
    ```
2.  **Настройте конфигурацию:**
    *   Откройте `config.json` и настройте провайдеров, модели и их параметры (`temperature`, `top_p`, `max_tokens`).
3.  **Настройте системные промпты:**
    *   Отредактируйте файлы в папке `system_prompts/`.
4.  **Запустите скрипт:**
    *   В файле `agents/main.py` раскомментируйте строку `asyncio.run(main())`.
    *   Выполните команду:
        ```bash
        python agents/main.py
        ```
5.  **Результаты:**
    *   Процесс обсуждения будет сохранен в `all_plans.txt`.
    *   Итоговый план будет доступен в `final_plan.txt`.
