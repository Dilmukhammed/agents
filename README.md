# Система агентов для составления плана действий

Этот проект представляет собой систему агентов, использующих несколько языковых моделей (LLM) для совместной разработки плана действий. Процесс состоит из трех этапов:

1.  **Генерация первоначальных планов:** Несколько LLM параллельно создают свои варианты плана в формате JSON (`PlanResponse`).
2.  **Циклические дебаты:** Модели вступают в многораундовые дебаты. В каждом раунде они могут атаковать планы соперников, защищать свои и уступать в спорах, используя JSON-структуру `DebateResponse`. Если модель уверена в своем плане, она может отправить его как финальный (`move: "submit_final_plan"`) и выйти из дебатов. Дебаты продолжаются, пока не останется один или ноль участников.
3.  **Создание финального плана:** Отдельная LLM анализирует все планы, представленные во время дебатов, и создает из них единый, итоговый план в том же формате JSON (`PlanResponse`).

## Структура проекта

*   `agents/`: Пакет Python, содержащий всю логику.
    *   `__init__.py`: Делает `agents` пакетом.
    *   `main.py`: Основной файл с логикой работы агентов.
    *   `schemas.py`: Файл с Pydantic-моделями.
*   `config.json`: Файл конфигурации для указания моделей и API-ключей.
*   `system_prompts/`: Папка с текстовыми файлами системных промптов для каждого этапа.
*   `all_plans.txt`: Файл, в котором сохраняется вся история: первоначальные планы, каждый раунд дебатов и представленные финальные планы.
*   `final_plan.txt`: Файл с итоговым, консолидированным планом в формате JSON.

## Инструкция по запуску

1.  **Установите зависимости:**
    ```bash
    pip install openai pydantic
    ```
2.  **Настройте конфигурацию:**
    *   Откройте `config.json` и настройте провайдеров, модели и их параметры.
3.  **Настройте системные промпты:**
    *   Отредактируйте файлы в папке `system_prompts/`.
4.  **Запустите скрипт:**
    *   В файле `agents/main.py` раскомментируйте строку `asyncio.run(main())`.
    *   Выполните команду из **корневой директории проекта**:
        ```bash
        python -m agents.main
        ```
5.  **Результаты:**
    *   Весь процесс, включая дебаты, будет сохранен в `all_plans.txt`.
    *   Итоговый JSON-план будет доступен в `final_plan.txt`.
