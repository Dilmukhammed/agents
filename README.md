# Система агентов для составления плана действий

Этот проект представляет собой систему агентов, использующих несколько языковых моделей (LLM) для совместной разработки плана действий. Процесс состоит из трех этапов:

1.  **Генерация первоначальных планов:** Несколько LLM параллельно создают свои варианты плана на основе запроса пользователя.
2.  **Обсуждение и доработка:** Модели анализируют планы друг друга, высказывают критику и предложения по улучшению.
3.  **Создание финального плана:** Отдельная LLM анализирует все предложения и создает единый, итоговый план.

## Структура проекта

*   `agents/main.py`: Основной файл с логикой работы агентов.
*   `config.json`: Файл конфигурации для указания моделей и API-ключей.
*   `system_prompts/`: Папка с текстовыми файлами системных промптов для каждого этапа.
    *   `stage_1_prompts.txt`: Промпты для генерации первоначальных планов.
    *   `stage_2_prompts.txt`: Промпты для обсуждения и критики.
    *   `stage_3_prompts.txt`: Промпт для создания финального плана.
*   `all_plans.txt`: Файл, в котором сохраняются первоначальные планы и обсуждения.
*   `final_plan.txt`: Файл с итоговым планом.

## Инструкция по запуску

1.  **Установите зависимости:**
    ```bash
    pip install openai
    ```
2.  **Настройте конфигурацию:**
    *   Откройте `config.json`.
    *   В секции `"providers"` укажите ваши API-ключи и, при необходимости, `base_url` для каждого провайдера.
    *   В секциях `"stage_1_models"`, `"stage_2_models"` и `"stage_3_model"` укажите, какие модели вы хотите использовать на каждом этапе. Для каждой модели можно указать `temperature`, `top_p`, `max_tokens` и `reasoning_effort`. Если какой-либо из этих параметров не указан (или `null`), он не будет использоваться при вызове API.
3.  **Настройте системные промпты:**
    *   Откройте файлы в папке `system_prompts/` и отредактируйте их в соответствии с вашими задачами.
    *   Для `stage_1_prompts.txt` и `stage_2_prompts.txt` вы можете указать один промпт для всех моделей или несколько, разделив их `---`.
4.  **Запустите скрипт:**
    *   В файле `agents/main.py` раскомментируйте строку `asyncio.run(main())`.
    *   Выполните команду:
        ```bash
        python agents/main.py
        ```
5.  **Результаты:**
    *   Процесс обсуждения будет сохранен в `all_plans.txt`.
    *   Итоговый план будет доступен в `final_plan.txt`.
